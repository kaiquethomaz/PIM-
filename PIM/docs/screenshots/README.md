# Screenshots

As imagens abaixo são usadas no `README.md` da raiz do projeto. Para (re)gerá-las:

1. Suba a aplicação em modo demo (veja o README principal):
   - API: `cd PIM/src/Inventory.Api && dotnet run`
   - Front: `cd PIM/front && node server.js`
2. Acesse `http://localhost:8080` e faça login com `admin@inventory.local` / `Admin@123`.
3. Capture cada tela e salve nesta pasta com os nomes exatos:

| Arquivo           | Tela                                  |
| ----------------- | ------------------------------------- |
| `login.png`       | Tela de login (`/login.html`)         |
| `dashboard.png`   | Dashboard com KPIs e gráficos         |
| `estoque.png`     | Listagem de estoque                   |
| `relatorios.png`  | Relatórios                            |

Dica: para telas mais limpas, use uma janela de ~1280px de largura.
